Fundamentos de Vectores y Movimiento

Un vector es un segmento de recta orientado que permite representar magnitudes físicas definidas por su magnitud (longitud), dirección (orientación respecto a un eje) y sentido (hacia dónde apunta la flecha).

Componentes Rectangulares en 2D

Todo vector A en un plano puede descomponerse en la suma de dos vectores perpendiculares sobre los ejes x e y:

A_x = |A| · cos(θ)
A_y = |A| · sin(θ)

Magnitud y Dirección

Conocidas las componentes cartecianas (A_x, A_y):

Magnitud: |A| = √(A_x² + A_y²)
Dirección: θ = arctan(A_y / A_x)

Operaciones Vectoriales

Suma de Vectores

Suma componente a componente (fuerza o desplazamiento resultante):

R_x = A_x + B_x
R_y = A_y + B_y

Producto Escalar (Punto)

Devuelve un escalar. Se utiliza para calcular trabajo mecánico:

A · B = A_x·B_x + A_y·B_y
A · B = |A||B|cos(θ)

Nivel FÁCIL

Suma Directa por Componentes

Problema: Dos fuerzas actúan sobre un mismo punto: F1 = (3, 4) N y F2 = (5, -2) N. Determinar la fuerza resultante R y su magnitud.

Solución Paso a Paso:

1. Sumar las componentes x e y independientemente:

R_x = 3 + 5 = 8 N
R_y = 4 + (-2) = 2 N

2. Aplicar el Teorema de Pitágoras para la magnitud:

|R| = √(8² + 2²) = √(64 + 4) = √68 ≈ 8.25 N
Nivel MEDIO

Descomposición de Vectores de Movimiento

Problema: Un vehículo se desplaza con un vector velocidad de magnitud v = 12 m/s a un ángulo de 135° respecto al eje positivo X. Encontrar sus componentes cartesianas.

Solución Paso a Paso:

v_x = 12 · cos(135°) = 12 · (-0.7071) = -8.49 m/s
v_y = 12 · sin(135°) = 12 · (0.7071) = 8.49 m/s

Resultado: El vector velocidad es v = (-8.49, 8.49) m/s

Nivel DIFÍCIL

Equilibrio Estático en Cargas Sostenidas

Problema: Una carga de 120 N se sostiene mediante dos cuerdas A y B fijadas al techo. La cuerda A forma un ángulo de 30° con la horizontal y la B un ángulo de 60°. Calcular la tensión en cada cuerda.

Solución Paso a Paso:

Se establece el sistema en equilibrio según las leyes de Newton (ΣF = 0):

ΣF_x = -Ta·cos(30°) + Tb·cos(60°) = 0
ΣF_y = Ta·sin(30°) + Tb·sin(60°) - 120 = 0

Despejando y sustituyendo en el sistema lineal:

Ta = 60 N
Tb = 103.92 N

Aplicaciones Directas en la Ingeniería

1. Ingeniería Civil y Estructuras

Análisis de armaduras y cerchas mediante el método de los nodos. Los vectores permiten modelar la distribución de cargas para asegurar que los elementos estructurales no excedan los límites de resistencia del material.

2. Robótica y Mecatrónica

Sistemas de coordenadas cinemáticas directas e inversas. Los vectores representan la posición, orientación y velocidad lineal/angular de cada articulación de un brazo robótico industrial.

3. Sistemas de Navegación y Telecomunicaciones

Modelado del movimiento de aeronaves frente a corrientes de viento cruzado mediante suma vectorial de velocidades para corregir trayectorias de vuelo automáticamente.
